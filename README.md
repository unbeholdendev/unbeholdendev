I'm Jakub. I self-host what I can, and run open source where a good option exists.

When something I need doesn't exist, or only exists as a service someone could take away, I write it and publish it here. It's usually small and solves one specific problem.

- [dotfiles](https://github.com/unbeholdendev/dotfiles) is one Nix flake for NixOS and niri on two ThinkPads, plus Home Manager config for a headless host and dev containers.
- [infra](https://github.com/unbeholdendev/infra) is a homelab in Git. Ansible sets up the hosts, OpenTofu creates the VMs and Flux reconciles the Kubernetes cluster.
- [unbeholden-wallet](https://github.com/unbeholdendev/unbeholden-wallet) is a watch-only Bitcoin wallet in a browser tab. It connects to a node of your choosing and never holds a private key.
- [reviewer](https://github.com/unbeholdendev/reviewer) is a code review bot for Forgejo. It reviews pull requests and answers questions in the comments.
- [unbeholden-lnurl](https://github.com/unbeholdendev/unbeholden-lnurl) is a small Lightning Address server in Go. Payments to you@yourdomain are invoiced by your own LND node.
- [lnrecc](https://github.com/unbeholdendev/lnrecc) sends recurring Lightning payments from your LND node, on a cron schedule.

The rest is on [Built](https://unbeholden.dev/built). I write about running all of it at [unbeholden.dev](https://unbeholden.dev), and my [CV](https://unbeholden.dev/cv) is there too.
